# Accessible profile copy

Write concise descriptions that convey the real content of each generated
visual without adding unsupported claims.

- Derive names, counts, dates, rankings, and periods from parsed profile data
  or the same calculation used to draw the visual.
- Describe what encodings mean only when code confirms the mapping. Avoid
  implying exactness for rounded or estimated values.
- Include the relevant period and configured timezone when time or dates could
  otherwise be ambiguous.
- Keep decorative details secondary to the information a screen-reader user
  needs. Avoid repeating section headings without adding meaning.
- Check generated README `alt` text as well as SVG `<title>` and `<desc>`.
